# ai-cohort-assignments

🎓 Notes, materials and self-assessment kits for 6 completed AI cohorts.

**Live site:** https://rifaterdemsahin.github.io/ai-cohort-assignments/ (enable Pages → GitHub Actions in repo settings to activate)

## Structure

- `index.html` — homepage
- `cohorts/` — upload each cohort's session notes here as `cohort-1.docx` … `cohort-6.docx` (see `cohorts/README.md`)
- `assessments/` — self-scored, per-session checklist for each cohort
- `glossary/` — dictionary of AI/GitHub terms used across cohorts
- `.github/workflows/pages.yml` — deploys the site to GitHub Pages on every push to `main`
