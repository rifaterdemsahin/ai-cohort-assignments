📖 Glossary

Terms you'll run into across the cohorts — both AI concepts and the GitHub workflow. Type below to filter.

A🤖 Agent

A program that uses an AI model to plan and take actions — calling tools, reading files, or hitting APIs — rather than just answering a single question.

A🔌 API (Application Programming Interface)

A defined way for one piece of software to talk to another — how your code asks an AI model (or any service) to do something.

A🔑 API Key

A secret credential that authenticates your requests to a service. Never commit one to a public repository.

B🌿 Branch

A parallel line of development in a Git repository, letting you work on changes without touching the main codebase until you're ready.

C🎓 Capstone Project

The final project of a cohort — a chance to combine everything learned into one deployed, working piece of work.

C🧠 Claude Code

Anthropic's CLI-based coding agent — used in several cohort sessions to read, write and run code directly from natural-language instructions.

C📝 Commit

A saved snapshot of changes in a Git repository, with a message describing what changed and why.

C🪟 Context Window

The amount of text (measured in tokens) an AI model can "see" at once — including your prompt, conversation history, and any documents provided.

E🧬 Embedding

A numeric representation of text that captures its meaning, allowing a computer to compare how similar two pieces of text are.

F🎛️ Fine-tuning

Further training a base AI model on your own examples so it performs better on a specific task or style.

G🐙 GitHub

A hosted platform for Git repositories — where cohort code, notes and this very site live and get deployed from.

H👻 Hallucination

When an AI model confidently states something false or made-up. Always verify important claims from a model's output.

L🗣️ LLM (Large Language Model)

The type of AI model (like Claude) trained on huge amounts of text to understand and generate human-like language.

M🔗 MCP (Model Context Protocol)

An open standard that lets AI assistants connect to external tools and data sources — files, databases, apps — in a consistent way.

P💬 Prompt

The instruction or question you give an AI model. How you phrase it — how specific, how much context — strongly shapes the response.

P🔀 Pull Request (PR)

A request to merge changes from one branch into another, giving others a chance to review the code first.

R📚 RAG (Retrieval-Augmented Generation)

A technique where relevant documents are retrieved and fed into an AI's prompt so it can answer using your own data, not just what it was trained on.

R📂 Repository (Repo)

A project's folder tracked by Git, containing all its files and their full history of changes.

S⚙️ System Prompt

Background instructions given to an AI model before the conversation starts, setting its role, tone or constraints.

T🌡️ Temperature

A setting that controls how random or predictable an AI model's output is — low temperature is focused and consistent, high is more varied.

T🪙 Token

A chunk of text (roughly a word or part of one) that an AI model reads and generates — used to measure both context size and cost.

V🗄️ Vector Database

A database built to store and search embeddings efficiently — the backbone of most RAG systems.
