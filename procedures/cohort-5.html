COHORT 5 · 🧠 Models, Prompting & Cost

🔗 Practiced zero-shot, few-shot, and chain-of-thought prompting

🎯 Objective
Try all three core prompting techniques on the same task to feel the difference.
✅ Key Results
  • One zero-shot prompt attempted
  • One few-shot prompt (with examples) attempted
  • One chain-of-thought prompt attempted
📋 Prerequisites
  • Access to any AI chat tool
🪜 Steps
  1. Pick one task (e.g. classifying text or solving a small logic problem)
  2. Try it zero-shot (no examples, no reasoning instruction)
  3. Try it few-shot (give 2-3 examples first)
  4. Try it chain-of-thought (ask it to reason step by step)
  5. Compare the quality of the three outputs
🔗 References
  • Cohort 5 session notes

🪜 Steps

COHORT 5 · 📚 RAG & Guardrails

🛡️ Wrote or reviewed a guardrail to prevent an unwanted AI action (e.g. blocking deletes)

🎯 Objective
Put at least one real guardrail in place to limit what an AI agent can do.
✅ Key Results
  • One guardrail written (even a simple rule/config) restricting a risky action
  • Guardrail tested by attempting the blocked action
📋 Prerequisites
  • Understand guardrails vs. hooks (previous step)
🪜 Steps
  1. Pick one risky action to restrict (e.g. deleting files, dropping database records)
  2. Write a simple rule/config/prompt instruction that blocks it
  3. Test it by asking the AI to perform that exact action and confirm it's refused
