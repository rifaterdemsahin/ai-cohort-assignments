COHORT 4 · 💻 CLI Setup

⬇️ Installed Node.js and the Claude Code CLI

🎯 Objective
Get the Claude Code CLI installed and runnable on your machine.
✅ Key Results
  • `node -v` returns a version number
  • Claude Code CLI installed and its help command runs
📋 Prerequisites
  • Administrator/terminal access on your computer
🪜 Steps
  1. Install Node.js from nodejs.org (or via Homebrew/winget)
  2. Open a terminal (PowerShell as admin on Windows, Terminal on Mac)
  3. Install the Claude Code CLI following its official install command
  4. Run its version/help command to confirm installation
🔗 References
  • Node.js
  • Claude Code docs
  • Cohort 4 session notes
COHORT 4 · 💻 CLI Setup

🔑 Authenticated the CLI via the browser flow

🎯 Objective
Complete first-time authentication so the CLI can make requests on your behalf.
✅ Key Results
  • Browser login flow completed
  • CLI confirms an authenticated session
📋 Prerequisites
  • CLI installed (previous step)
  • An Anthropic/Claude account
🪜 Steps
  1. Run the CLI's login command
  2. Complete the sign-in in the browser window it opens
  3. Paste back any authentication code if prompted
  4. Confirm the terminal shows you as logged in
🔗 References
  • Claude Code docs

COHORT 4 · 🗂️ File & Context Management

☁️ Set up a cloud backup (e.g. OneDrive) before letting AI touch your files

🎯 Objective
Have a safety net in place before giving an AI agent write access to real files.
✅ Key Results
  • A cloud-synced backup folder (OneDrive, Google Drive, etc.) is active
  • Version history confirmed accessible for at least one file
📋 Prerequisites
  • A cloud storage account
🪜 Steps
  1. Set up or confirm OneDrive/Google Drive sync on your working folder
  2. Check that version history is enabled for that location
  3. Only then let the CLI make bulk changes in that folder
🔗 References
  • Cohort 4 session notes
