COHORT 2 · 🤖 Agentic Systems

🚗 Can explain the difference between an agentic system and a simple prompt (autopilot analogy)

🎯 Objective
Be able to distinguish an agentic system from a single prompt-response exchange.
✅ Key Results
  • Can explain the autopilot-vs-manual-driving analogy from the session
  • Can give one real example of each type of system
📋 Prerequisites
  • None
🪜 Steps
  1. Re-read or re-watch the "defining agentic systems" section of Cohort 2
  2. Write one example of a plain prompt task and one example of an agentic task
  3. Explain the difference to a peer or write it down in your own words
🔗 References
  • Cohort 2 session notes
  • Glossary: Agent
COHORT 2 · 🤖 Agentic Systems

🧭 Understand coordinator vs. sub-agent roles in an architecture

🎯 Objective
Understand the coordinator/sub-agent split in multi-agent systems.
✅ Key Results
  • Can state what a coordinator does vs. what a sub-agent does
  • Can name one benefit of splitting responsibilities this way
📋 Prerequisites
  • Completed: agentic vs. prompt distinction (previous step)
🪜 Steps
  1. Review the coordinator/sub-agent explanation in the Cohort 2 notes
  2. Sketch a simple diagram: one coordinator box with 2-3 sub-agent boxes
  3. Label what each sub-agent would be responsible for in a sample workflow
🔗 References
  • Cohort 2 session notes
COHORT 2 · 🤖 Agentic Systems

🏙️ Reviewed an example of interconnected agents (e.g. a document/PDF-parsing pipeline)

🎯 Objective
Study one concrete example of multiple agents working together on a real task.
✅ Key Results
  • Reviewed the city-council PDF-parsing example (or an equivalent)
  • Can describe the flow from input document to final output in 3-4 steps
📋 Prerequisites
  • Understand coordinator vs. sub-agent roles (previous step)
🪜 Steps
  1. Re-read the interconnected-agents example from Cohort 2
  2. List the pipeline stages in order (intake → parse → error handling → output)
  3. Note which stage a coordinator vs. a sub-agent would own
🔗 References
  • Cohort 2 session notes
COHORT 2 · 🪙 Token & Cost Management

📊 Tracked your own daily token usage across at least one AI tool

🎯 Objective
Build the habit of monitoring your own token consumption.
✅ Key Results
  • Logged your token usage for at least one full day
  • Recorded the figure somewhere you can compare next week
📋 Prerequisites
  • Access to a usage/billing dashboard (see Cohort 1)
🪜 Steps
  1. Check your AI tool's usage dashboard at the start and end of a working day
  2. Record the token count and rough cost
  3. Repeat for a few days to spot a pattern
🔗 References
  • Cohort 2 session notes
COHORT 2 · 🪙 Token & Cost Management

💳 Understand the difference between subscription-based and API/pay-per-use pricing

🎯 Objective
Know when a flat subscription makes more sense than pay-per-use API billing.
✅ Key Results
  • Can explain both pricing models in one sentence each
  • Can name a scenario where each model is the better economic choice
📋 Prerequisites
  • None
🪜 Steps
  1. Compare your AI tool's subscription price to its per-token API price for the same model
  2. Estimate your own monthly usage to see which pricing model would be cheaper for you
  3. Write down your conclusion
🔗 References
  • Cohort 2 session notes

🧮 Know what a benchmark (SB) score is used for when comparing models

🗂️ Tried local indexing (e.g. with Ollama) instead of a cloud-only workflow
