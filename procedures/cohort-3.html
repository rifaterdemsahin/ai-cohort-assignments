COHORT 3 · 🧩 Multi-Agent Architecture

🤖 Can explain the difference between a "robot" and an "agent" (agency = decision-making)

🎯 Objective
Be able to distinguish "agency" (decision-making capability) from simple automation.
✅ Key Results
  • Can define "agency" in one sentence
  • Can give an example of a robot task vs. an agentic task
📋 Prerequisites
  • None
🪜 Steps
  1. Re-read the robot-vs-agent discussion in Cohort 3
  2. Write your own one-sentence definition of "agency"
  3. Give one example each of a simple robot task and a decision-making agent task
🔗 References
  • Cohort 3 session notes
  • Glossary: Agent
COHORT 3 · 🧩 Multi-Agent Architecture

🔀 Understand the hub-and-spoke pattern (coordinator + specialized sub-agents)

🎯 Objective
Understand hub-and-spoke as the standard multi-agent architecture pattern.
✅ Key Results
  • Can draw or describe a hub-and-spoke diagram from memory
  • Can explain why bypassing the coordinator causes problems
📋 Prerequisites
  • Understand robot vs. agent (previous step)
🪜 Steps
  1. Re-read the hub-and-spoke explanation in Cohort 3
  2. Sketch a coordinator with 2-3 spokes (sub-agents) around it
  3. Explain in one sentence why the coordinator step can't be skipped
🔗 References
  • Cohort 3 session notes
COHORT 3 · 🧩 Multi-Agent Architecture

🧵 Understand the role of a synthesis agent in combining results

🎯 Objective
Understand why a synthesis step is needed when multiple agents produce partial results.
✅ Key Results
  • Can explain what a synthesis agent does in one sentence
  • Can name one problem that occurs without a synthesis step
📋 Prerequisites
  • Understand the hub-and-spoke pattern (previous step)
🪜 Steps
  1. Re-read the synthesis-agent section of Cohort 3
  2. Consider a scenario with two search agents producing different results
  3. Explain how a synthesis agent would combine them into one coherent answer
🔗 References
  • Cohort 3 session notes
COHORT 3 · 🎬 Multimedia Learning Workflow

🎨 Built a storyboard or script for a concept using Canva

🎯 Objective
Produce a first storyboard/script draft for one AI concept you're learning.
✅ Key Results
  • A Canva project created with at least 3 storyboard frames
  • Script text drafted for each frame
📋 Prerequisites
  • A Canva account
🪜 Steps
  1. Create a new Canva project
  2. Pick one concept from this course (e.g. hub-and-spoke)
  3. Draft 3+ frames with a one-line script each
🔗 References
  • Canva

COHORT 3 · 🎬 Multimedia Learning Workflow

🎙️ Added an AI voiceover and captions to a slide/video

COHORT 3 · 🎬 Multimedia Learning Workflow

🗣️ Did a "table read" of a script to check understanding of roles/flow

🎯 Objective
Read your script aloud (or with a peer) to verify you actually understand the flow, not just the words.
✅ Key Results
  • Full script read aloud once, start to finish
  • Any confusing section identified and rewritten
📋 Prerequisites
  • Script drafted (see storyboard step)
🪜 Steps
  1. Read your script out loud by yourself or with a cohort peer
  2. Note any part where you stumble or aren't sure what happens next
  3. Rewrite that section for clarity
🔗 References
  • Cohort 3 session notes

🖼️ Personalized a visual using your own life references (memory-palace technique)

🎯 Objective

✅ Key Results
  • At least one visual/image tied to a real place or memory of yours

COHORT 3 · 📈 Exam & Market Research

📊 Used Google Trends to compare interest in two technologies or AI tools

🎯 Objective
Use search-trend data to inform a real technology or career decision.
✅ Key Results
  • A Google Trends comparison chart created for 2+ terms
  • One conclusion drawn from the data (e.g. which to prioritize learning)
📋 Prerequisites
  • None
🪜 Steps
  1. Go to Google Trends
  2. Add two or more terms (e.g. "Claude" vs. "Gemini", or two technology stacks)
  3. Set a multi-year range and note the trend direction
  4. Write one sentence on what the trend suggests you should prioritize
🔗 References
  • Google Trends
